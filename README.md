# استديو نور التفاعلي — v1.0.0

إضافة Firefox مستقلة لتأليف التحاضير العربية؛ لا تعدّل مستودع noor-learning-studio ولا حقول منصة نور.

## التشغيل

1. نزّل `dist/noor-interactive-preparations-v1.0.0.zip` وفك الضغط.
2. افتح `about:debugging#/runtime/this-firefox`، اختر «تحميل إضافة مؤقتة»، ثم `manifest.json`.
3. اضغط أيقونة الإضافة لفتح الاستديو.

هذه حزمة تطوير غير موقعة؛ تنتهي الإضافة المؤقتة عند إغلاق Firefox. التثبيت الدائم يحتاج مراجعة وتوقيع Mozilla. لا تدّعي هذه النسخة التحقق داخل Firefox أو داخل منصة نور إن لم يتم ذلك.

## الميزات

ستة أقسام، حفظ مسودة وإصدارات (25 إصدارًا)، استيراد وتصدير JSON، معاينة جوال ومعلم وطالب، بطاقات قلب، أسئلة عشوائية، مؤقتات، قوائم تحقق، اختبارات مع إعادة المحاولة، احتفال وصوت اختياري. يعمل المحتوى محليًا دون خدمات خارجية. التأليف بقوالب محلية؛ لا يوجد نموذج ذكاء اصطناعي مدمج.

النص الأصلي محفوظ بالكامل كنص آمن، وتضاف المعلومات التربوية منفصلة. لا تُنفذ HTML أو سكربتات مستوردة. الحصص 1–8 والدقائق 10–120؛ توزيع المراحل يحدده المعلم يدويًا. مؤشر الاكتمال لا يتحقق من صحة المحتوى أو جودته التربوية.

## التصدير

- HTML مستقل لكل قسم أو للأقسام مجتمعة، CSS وJS داخليان، بلا مكتبات أو خطوط خارجية.
- HTML منسق للقسم الحالي بلا JavaScript: نسخه إلى وضع HTML في محرر نور **يدويًا** بعد حفظ محتوى الحقل السابق. ليس هناك إدراج تلقائي أو نشر أو وصول لصفحات نور.
- توافق نسخة نور يحتاج اختبارًا في المحرر الفعلي الذي قد يزيل التنسيق.
- وضع الطالب يخص المعاينة؛ التصدير يضم المعلومات التربوية للمعلم.
- الأسئلة المقالية تسجّل الرد في الصفحة الحالية ولا تصححه آليًا. إكمال الاختبار يقيس النجاح بعد إعادة المحاولة. الإجابات لا تُحفظ بعد تحديث المعاينة.

## التطوير والفحص

`node tests/smoke.cjs` لاختبار المتصفح والتصدير والحفظ والاستيراد. `python3 scripts/package.py` لإنشاء الحزمة. لا يحتاج المشروع بناء npm.

تصميم تعليمي للأستاذ أحمد الضامري.
